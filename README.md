# برنامه‌ریز مطالعه

یک پروژه تک‌صفحه‌ای برای برنامه‌ریزی هفتگی و ثبت گزارش کار روزانه، با Vue 3 از CDN و ذخیره‌سازی در `localStorage`.

## اجرا

1. در پوشه پروژه، فایل `index.html` را باز کنید.
2. یا از یک سرور محلی ساده استفاده کنید:

```bash
cd /home/mohammad/code/web/schedule
python3 -m http.server 8000
```

سپس به آدرس `http://localhost:8000` بروید.

## انتشار روی GitHub Pages

1. فایل `index.html` را در ریشه مخزن GitHub خود قرار دهید.
2. تنظیمات Pages را روی `Deploy from a branch` و شاخه `main` یا `master` تنظیم کنید.
3. پروژه با CDN و فایل HTML به‌صورت مستقیم روی GitHub Pages اجرا می‌شود.

## توضیح ذخیره‌سازی

- داده‌های اصلی در `localStorage` مرورگر ذخیره می‌شوند.
- فایل TXT فقط برای خروجی قابل‌اشتراک‌گذاری و دانلود است و به‌عنوان منبع اصلی داده‌ها استفاده نمی‌شود.
- برای پشتیبان‌گیری، فایل JSON قابل دانلود و بازیابی است.

## محدودیت‌ها

- برای اجرا کامل، مرورگر باید دسترسی به CDN داشته باشد.
- اگر اینترنت قطع باشد، باید نسخه محلی کتابخانه‌های CDN به پروژه اضافه شود.
- `localStorage` در برخی محیط‌ها محدودیت فضای ذخیره‌سازی دارد، اما برای نیازهای این برنامه کافی است.
